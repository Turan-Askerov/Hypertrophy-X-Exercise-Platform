# Hypertrophy-X 💪

Hypertrophy-X, kullanıcıların antrenman süreçlerini ve günlük beslenme (makro/kalori) hedeflerini detaylı bir şekilde takip etmelerini sağlayan kapsamlı bir web uygulamasıdır. 

Kullanıcı dostu arayüzü sayesinde günlük verilerinizi girebilir, antrenman hacminizi hesaplayabilir ve gelişiminizi interaktif grafiklerle analiz edebilirsiniz.

## 🌟 Özellikler

- **🏋️‍♂️ Antrenman Takibi:** Günlük antrenmanlarınızı, hareketlerinizi, set, tekrar ve ağırlık bazında kaydedin.
- **🥗 Beslenme ve Makro Takibi:** Günlük kalori, protein, karbonhidrat ve yağ alımınızı hedeflerinizle karşılaştırın.
- **📊 İnteraktif Grafikler (Chart.js):** Haftalık, aylık ve genel zaman dilimlerinde gelişiminizi (hacim artışı, kalori/makro trendleri) çizgi grafiklerle analiz edin.
- **📅 Özel Program Oluşturucu:** Kendinize özel antrenman splitleri (Push/Pull/Legs vb.) hazırlayın.
- **📱 Esnek Tasarım (Responsive):** Mobilde ve masaüstünde sorunsuz çalışan kullanıcı dostu arayüz.

## 🛠️ Kullanılan Teknolojiler

- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Grafikler & Analiz:** Chart.js
- **Backend:** Python (API Motoru)
- **Veritabanı:** SQLite
